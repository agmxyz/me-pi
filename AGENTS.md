- `GLOBAL_AGENTS.md` is the live policy of every new Pi session and worker (linked as `~/.pi/agent/AGENTS.md`); `skills/*/` are live user skills (linked under `~/.pi/agent/skills/`). Editing either changes what new or reloaded sessions load.
- `packages/pi-workers/` is the published `@agmxyz/pi-workers` package; the root package is the private setup, and its `extensions/{delegate,guard,skill}.ts` re-export the package entrypoints so existing Git installs and filters keep working. `packages/pi-workers/extensions/delegate.ts` orchestrates delegate jobs; each concern has one owner beside it: `delegate-config` (model pools, model refs), `delegate-worker` (roles, prompts, worker-side hooks, launch args/env) with `delegate-env` (the env protocol), `delegate-process` (child process lifecycle), `delegate-attempt` (Pi-event ledger per attempt), `delegate-provenance` (event decoding, effect facts), `delegate-implement` (checkout, check freshness, commit lifecycle), `delegate-fence` (secret and write path rules), `delegate-artifacts`, `delegate-render` (TUI), `delegate-command` (`/delegate`). `guard.ts` is the bash guard extension (parser init, live env, dirty check, worker rules); beside it: `guard-shell` (tree-sitter loading and bash parsing), `guard-policy` (the 3-case policy, also over bash-truth argv), `guard-resolve` (variable values), `guard-disk` (read-only git lookups, timeouts, budget), `guard-git` (git's sub-commands, data-only `-c` keys, string-running options, long-option prefixes), `guard-regex` (0.1.3's regex `classify` fallback, `workerRisk`, `gitTreeWrite`); `test/guard-truth/` is its local-only proof harness.
- Current guides: [`README.md`](README.md) (setup, releasing), [`packages/pi-workers/README.md`](packages/pi-workers/README.md) (package install), [`packages/pi-workers/docs/delegate.md`](packages/pi-workers/docs/delegate.md) (delegation and recovery), [`docs/setup.md`](docs/setup.md) (full rig); dated checkpoints are historical—use guides and code for current behavior.
- Run `./install.sh` only from the live checkout's main session, never from a worktree, temp clone, or worker: it registers this checkout's path in `~/.pi/agent/settings.json`. A pointer to a new installed path needs its link in `install.sh` and an `./install.sh` run first.
- A user-visible change to `packages/pi-workers/` adds its line under `## [Unreleased]` in that package's `CHANGELOG.md`.
- A code change is done when `npm run check --prefix extensions` passes.
- When changing or reviewing code, follow [`docs/coding-standards.md`](docs/coding-standards.md).
