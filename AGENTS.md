- `GLOBAL_AGENTS.md` is the live policy of every new Pi session and worker (linked as `~/.pi/agent/AGENTS.md`); `skills/*/` are live user skills (linked under `~/.pi/agent/skills/`). Editing either changes what new or reloaded sessions load.
- `packages/pi-goblins/` is the published `@agmxyz/pi-goblins` package; the root package is the private setup, and its `extensions/{delegate,guard,skill}.ts` re-export the package entrypoints so existing Git installs and filters keep working. `packages/pi-goblins/extensions/delegate.ts` orchestrates delegate jobs; each concern has one owner beside it: `delegate-config` (model pools, model refs), `delegate-worker` (roles, prompts, worker-side hooks, launch args/env) with `delegate-env` (the env protocol), `delegate-process` (child process lifecycle), `delegate-attempt` (Pi-event ledger per attempt), `delegate-provenance` (event decoding, effect facts), `delegate-implement` (checkout, check freshness, commit lifecycle), `delegate-fence` (secret and write path rules), `delegate-artifacts`, `delegate-render` (TUI), `delegate-command` (`/delegate`).
- Current guides: [`README.md`](README.md) (setup), [`packages/pi-goblins/README.md`](packages/pi-goblins/README.md) (package install), [`packages/pi-goblins/docs/delegate.md`](packages/pi-goblins/docs/delegate.md) (delegation and recovery), [`docs/setup.md`](docs/setup.md) (full rig); dated checkpoints are historical—use guides and code for current behavior.
- Run `./install.sh` only from the live checkout's main session, never from a worktree, temp clone, or worker: it registers this checkout's path in `~/.pi/agent/settings.json`. A pointer to a new installed path needs its link in `install.sh` and an `./install.sh` run first.
- A code change is done when `npm run check --prefix extensions` passes.
- When changing or reviewing code, follow [`docs/coding-standards.md`](docs/coding-standards.md).
