## Output
- Lead with the result; omit preamble, recap, and offers.
- Preserve exact code, paths, commands, identifiers, and error strings. Report failures, skips, unverified claims, uncertainty, and material risks on separate lines.
- Make documents and handoffs unambiguous.

## Engineering
Before implementation, code edits, debugging, tests, or code review, read `~/.agents/CODING_STANDARDS.md`.

## Authorization
Publish changes (push branches or create PRs) only with explicit user authorization for the named operation; a request to edit, test, review, or commit does not imply publication authority.

That authorization does not cover unrelated runs, repositories, remotes, or PR merges. Human approval gates and merge decisions remain human-owned.
