### Endpoint evidence correction (integrated Standards `bg83`)

The installed Pi 1.4.0 runtime does not make `ModelRegistry.find()`'s catalog `baseUrl` the effective request URL in all cases: `ModelRuntime.prepareRequest()` replaces it with `auth.baseUrl` from request-time auth, and GitHub Copilot's OAuth `toAuth()` derives a credential-specific endpoint. `ModelRegistry.getApiKeyAndHeaders()` resolves credentials and is not used for this check; the SDK exposes no credential-free effective-endpoint accessor. The GitLab Duo custom-provider example also changes the request model's base URL inside its stream implementation.

The parent registry snapshot does not bind a fresh child's effective destination: `pi --model` loads its own configuration and resolves request-time authentication after the prompt is supplied. Although some transports use catalog `model.baseUrl`, request-time auth can replace it, OAuth can derive a credential-specific endpoint, and provider extensions can alter the request model's URL. The SDK exposes no supported credential-free accessor or endpoint-only pin at the child request boundary. Therefore the delegate now disables all cross-model fallback, including transports whose catalog metadata appears direct or matching. It does not read credentials to try to establish the endpoint, change model/provider authority, or claim that parent metadata pins the child. The first selected candidate and exact-model behavior remain; shared budgets and provenance still apply to that one dispatched child.

Evidence: installed `dist/core/model-runtime.js` (`prepareRequest`), `dist/core/model-registry.js` and `dist/core/model-registry.d.ts` (`find`, `getApiKeyAndHeaders`, `isUsingOAuth`, registered-provider metadata), `@earendil-works/pi-ai/dist/auth/oauth/github-copilot.js` (`toAuth`), and `examples/extensions/custom-provider-gitlab-duo/index.ts`. Relevant Pi docs read: `docs/models.md`, `docs/providers.md`, `docs/custom-provider.md`, `docs/models-configuration.md`, `docs/configuration.md`, `docs/extensions.md`, `docs/sdk.md`, and their model/auth/provider cross-references.
